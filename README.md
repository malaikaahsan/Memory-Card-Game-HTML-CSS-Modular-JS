A fun, interactive browser-based **Memory Card Matching Game**. This project was built from scratch to demonstrate advanced DOM manipulation, game state management, and modern software architecture using **Modular JavaScript (ES6 Modules)**. 

**🚀 Live Demo:** [View the live game on Vercel](https://memory-card-game-html-css-modular-j.vercel.app/)

---

## 🚀 Features

* **Interactive Gameplay:** Click to flip cards and find matching pairs. The game handles flip animations and prevents clicking while cards are animating.
* **Match Detection Logic:** Custom algorithms to check if two selected cards match, keeping them face-up if they do, or flipping them back over if they don't.
* **Modular Architecture:** The JavaScript is split into clean, maintainable ES6 modules (separating UI logic, game state, and data), making the codebase scalable and easy to read.
* **Responsive Grid:** The game board utilizes CSS Grid to adapt beautifully to different screen sizes, from mobile phones to desktop monitors.

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** Vanilla CSS3
* **Logic:** Vanilla JavaScript (ES6 Modules using `import`/`export`)
* **Deployment:** Vercel

## 💻 Getting Started (Local Development)

Because this project uses **ES6 JavaScript Modules** (`<script type="module">`), you cannot simply double-click the `index.html` file to run it. Browsers block module loading via the `file://` protocol for security reasons. **You must use a local server.**

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/malaikaahsan/Memory-Card-Game-HTML-CSS-Modular-JS.git](https://github.com/malaikaahsan/Memory-Card-Game-HTML-CSS-Modular-JS.git)

  ```
   Navigate to the folder:

cd Memory-Card-Game-HTML-CSS-Modular-JS
  ```
Run a Local Server:

If you use VS Code, install the Live Server extension.

Right-click index.html and select "Open with Live Server".
